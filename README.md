## Adding a website

1. Add an entry to `assets/js/sites.js` (copy an existing one).
2. Put a 960×600 screenshot in `assets/img/shots/` and point `shot` at it.
3. If the site lives in a GitHub repo, set `repo` and the "last updated"
   date is fetched from GitHub automatically.

Plain HTML, CSS and JavaScript. No build step. Hosted with GitHub Pages.
